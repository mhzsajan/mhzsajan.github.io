01 The work

Seven things, every show

This is live responsibility, not a list of things I once did. The band plays; this is what has to be true before they can.

  • 01

    Show control

    Ableton Live with AbleSet — setlists, click tracks, tempo-synced backing that never drifts.

  • 02

    Vocals & guitar

    TC-Helicon VoiceLive 3 Extreme, presets switching automatically as the setlist moves.

  • 03

    Front of house

    Behringer WING — mixing the room and the monitor mix, alongside the band’s engineer.

  • 04

    Video

    VideoSync2 — backdrop video, lyric overlays and live camera feeds, all locked to the tempo.

  • 05

    Lighting

    MaestroDMX running audio-reactive, syncing to the performance instead of a cue list.

  • 06

    Timecode

    LTC generated live and distributed to the visuals and the lighting desk as one reference.

  • 07

    Cameras

    iPhone over NDI and Camo, Kinect, DSLRs and GoPros, cut on a Rodecaster Video.

02 Signal flow

One clock, one setlist

Everything downstream hangs off Ableton, with LTC timecode as the independent reference both the visuals and the lighting desk can lock to.

Ableton Live AbleSet setlist

  • click tracksmonitor mix
  • backing tracksPA · FOH
  • MIDIVoiceLive 3 → FOH / monitors
  • MIDIVideoSync2 → projector
  • MIDIMaestroDMX → lighting

LTC timecode independent reference

  • timecodeVideoSync2 · backdrop + live cam
  • timecodeMaestroDMX · audio-reactive DMX

04 Output

Things I built

If a show needed it and I couldn’t buy it, I wrote it. Most of this is open source.

  • Open sourcePython

    AbleBridgePlus

    An MCP server that gives any AI assistant — Claude, OpenCode, Cursor — 475 tools over Ableton Live. Local-first, MIT. Born from automating my own show prep.

    Repository →

  • LiveHTML

    songtimer

    Tap lyric timings while a song plays, nudge them, preview karaoke-style, export a standard .lrc. Audio never leaves the device.

    Try it →

  • Open sourcePython

    td-live-bridge

    TouchDesigner to Ableton Live. Ableton’s tempo, transport and clips exposed as CHOP channels, so the visuals can read the band’s clock directly.

    Repository →

  • Open sourceKotlin

    huekeys

    An Android keyboard that tints its keys to match the app you’re typing into. Flat two-tone per-app colours, no root, no Xposed.

    Repository →

  • Open sourceJavaScript

    lyric-studio

    A .lrc and an audio file in, a finished lyric video out. Built for VideoSync2 overlays on stage, with a hard font gate and a render-critique loop.

    Repository →

  • Open sourcePython

    nepali-legacy-fonts

    Makes any legacy Nepali font render in Chromium by generating that font’s own key-to-Unicode layout. Preeti-era fonts, no longer unreadable.

    Repository →

  • Client workJavaScript

    jptest

    A static mock-test platform for Japanese language proficiency, nursing care and food service certification exams. Vanilla HTML, CSS and JavaScript.

    Repository →

Also private: stagecraft, switchgod-bazar and the band’s internal tooling — real work, not open yet.
