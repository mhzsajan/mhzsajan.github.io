01 The work

Two jobs, one stack

Everything below is a live responsibility, not a list of things I once did. Most of it exists because a show needed it and nothing off the shelf did.

Live production

Show operation
Ableton Live with AbleSet — setlist control, click tracks, tempo-synced backing.
Vocals & guitar
TC-Helicon VoiceLive 3 Extreme, with automated preset switching synced to the setlist.
FOH & monitors
Behringer WING — front-of-house and monitor support alongside the band's engineer.
Visuals
VideoSync2 — tempo-synced backdrop video, lyric overlays, live camera feeds, blend modes.
Cameras
iPhone via NDI/Camo, Kinect, DSLRs, GoPros, Rodecaster Video switcher.
Lighting
MaestroDMX — autonomous audio-reactive control, synced to performance.
Timecode
LTC generated and distributed to visuals and lighting in real time.

02 Signal flow

The show rig

One clock, one setlist, everything downstream of it. Audio, video and lighting all hang off Ableton, with LTC timecode as the independent reference the visuals and the lighting desk can both lock to.

Ableton Live AbleSet setlist

  • click tracksmonitor mix
  • backing tracksPA · FOH
  • MIDIVoiceLive 3 → FOH / monitors
  • MIDIVideoSync2 → projector
  • MIDIMaestroDMX → lighting

LTC timecode independent reference

  • timecodeVideoSync2 · backdrop + live cam
  • timecodeMaestroDMX · audio-reactive DMX

03 Output

What I'm building

Open source

  1. AbleBridgePlus Python · MCP · Ableton An MCP server that gives any AI assistant — Claude, OpenCode, Cursor — 475 tools over Ableton Live. Local-first, no cloud, MIT licensed. Born from automating my own show prep. Repository →
  2. songtimer HTML · offline Tap lyric timings while a song plays, nudge them, preview karaoke-style, and export a standard .lrc. Audio never leaves the device. Try it live →
  3. AbleBridgePlus site HTML A plain-English tour of the MCP bridge and what it can do, for anyone who'd rather not read a README first. Visit →

Private the band's tooling, not open yet

  • stagecraft Python Live-show pipeline wiring Ableton, AbleSet, Videosync2 and TouchDesigner into a single performance system.
  • nepali-lyric-video-maker HTML Whisper-timed Nepali lyric videos — word-by-word karaoke MP4s, with shadow-key output for transparent live overlays. Handles pre-Unicode Preeti-era fonts.
  • StageCraft-Graphified / -RE HTML · Python Graphical companion and reverse-engineering toolkit for the pipeline.
  • switchgod-bazar / pickbazar TypeScript E-commerce platform work.
